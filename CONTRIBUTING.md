# Contributing

Corrections, clearer explanations, accessible diagrams and better public references are welcome. Please include the claim being changed, the supporting public source or authorized evidence summary, the substrate to which it applies, and its limitations.

Read [the editorial protocol](docs/EDITORIAL.md) before adding findings. Do not attach firmware, private logs, images, device identifiers or material that you cannot license. A public architectural reference can improve context without independently confirming a private experiment.

For site changes, run `npm test` and `npm run build`. Check the affected behavior in a browser at desktop and narrow widths, including keyboard use. Preserve reduced-motion behavior and access to research content without JavaScript.

Contributions to original publication content and site code are accepted under the MIT license. Preserve third-party license notices.

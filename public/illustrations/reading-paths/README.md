# Reading path illustrations

These three original conceptual illustrations were generated for the website using OpenAI's built-in image generation tool, following a reviewed design concept. They depict a boot contract, pixel presentation, and controlled comparison using stylized miniature objects. They are not research captures or evidence of a device run.

The original prompts and design comparisons are retained as local design artifacts. The published WebP files preserve transparency and are resized to 1000 × 667 pixels for the website. CPU state and pixel transfers use separate CSS elements; the generated objects do not depict a copied Apple interface or extracted artwork.

The website's reading links provide the actual chapters, environments, records and limits.

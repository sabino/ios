The read helper selects GPIO bank 7, bit 1: it reads a word at `0x3e400004 + 7 * 0x20 = 0x3e4000e4` and tests mask `0x2`. A zero result takes the branch to the radio-present message at `0x18000ed4`; a nonzero result prints that no radio board was detected.

The pinned QEMU `hw/arm/ipod_touch_gpio.c` handles only offset `0x2c4` in its read callback and returns zero for every other GPIO offset. Its write callback ignores all writes. Thus the read at offset `0xe4` supplies the low bit value that this iBEC interprets as an installed radio board. This explains the existing console observation without implying a working baseband.

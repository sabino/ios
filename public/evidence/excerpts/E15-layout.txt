The previous adapter used scanout RAM as the default CoreSurface backing.
Copying another surface into scanout therefore overwrote the default source,
and returning to the default surface skipped copying. The source now requires
a distinct, page-aligned default allocation with validated nonoverlapping
32-bit ranges, and copies every selected non-null surface. A host regression
executes setup and A → B → A presentation, checking whole-frame equality and
unchanged default-source contents alongside one-shot console ownership.

The main thread waits in HID session initialization during application
startup. The same worker whose kernel stack reaches AppleISL29003 has this
user call chain: HID session thread, service-set traversal, service
registration, ALS state setup, HID service open, IOKit connection method,
Mach message. Exact library analysis shows the worker signals readiness
only after these registration calls return. Its kernel-side sensor call
is blocked on a shared legacy IIC controller queue. Other kernel threads
also wait on that controller; this does not identify a sensor register
failure or prove that this particular transfer reached hardware.
